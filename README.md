# Internship & Placement Management System (IPMS)

## Description
The Internship & Placement Management System is a Java Object-Oriented Programming project developed to automate student placement activities.

## Features
- Student Registration
- Company Registration
- Placement Officer Module
- Job Management
- Internship Management
- Job Applications
- Interview Scheduling
- File Handling
- Validation

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- File Handling
- VS Code

## OOP Concepts Used
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interface

## Folder Structure

src/
├── main
├── model
├── service
├── database
├── utils
└── interfaces
